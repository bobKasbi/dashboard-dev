# Dashboard Dev

Angular 20 dashboard application built as a portfolio/reference project for modern frontend architecture, authentication integration, reusable UI components, and deployment-ready configuration.

## Tech Stack

- Angular 20
- TypeScript
- Angular Signals
- Standalone Components
- Angular Material
- Keycloak integration
- Docker
- Kubernetes / Helm
- GitLab CI/CD

## Features

- Authentication-ready dashboard structure
- Reusable generic table components
- Sorting, filtering, and pagination
- Responsive layout
- Environment-based configuration
- Deployment-ready Docker and Helm setup
- CI/CD pipeline configuration

## Architecture Highlights

- Standalone Angular components
- Signal-based state handling
- Reusable table architecture
- Separation between UI, configuration, and deployment concerns
- Kubernetes-ready deployment structure

## Local Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Notes

This repository is a cleaned public reference version of the dashboard development application.
Sensitive local files, certificates, and generated cache files are intentionally excluded.
